overview

A production-inspired but cost-conscious platform for publishing this portfolio. CloudFront is the TLS and caching boundary, while a private S3 bucket remains accessible only through Origin Access Control. Terraform owns the infrastructure and GitHub Actions handles validation and delivery.

  • ✓ Private, versioned and encrypted S3 origin
  • ✓ CloudFront TLS, caching and security headers
  • ✓ OIDC deployments without long-lived AWS keys
  • ✓ Logging, alarms and documented recovery procedures

architecture

features

01

Private delivery

CloudFront signs origin requests with OAC; the website bucket blocks all public access.

02

Passwordless CI/CD

Repository-scoped OIDC roles provide temporary credentials with bounded permissions.

03

Operational readiness

Versioning, access logs, alarms, cache policies and recovery documentation support safe operation.

lessons

What I learned

  • • Designing least-privilege OIDC trust and permissions
  • • Handling private-origin 403/404 behavior correctly
  • • Separating infrastructure apply from frontend delivery

Accepted trade-offs

  • • A single dev environment keeps portfolio costs low
  • • Full CloudFront invalidation favors simplicity at this scale
  • • WAF and multi-region recovery remain outside the demo scope
